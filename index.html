Selected work

Three recent projects

An enterprise architecture, a multi-user AI platform and a consumer app, each taken from problem to a concrete outcome.

Enterprise · Architecture & estimate

QA Control Tower

An AI pipeline that reads acceptance criteria from Jira, scans the application and its existing Playwright framework, and writes automation scripts that follow the team's Page Object Model conventions.

Problem

Automation trails behind development. Engineers rewrite the same page objects, and new tests drift away from the framework's conventions.

Design

Jira webhook→AC parser→Framework scanner→Semantic test index→Coverage resolver→POM generator→Validate & PR

Highlights

  • A framework profile so generated code reads like your team wrote it
  • Checks whether a scenario is new, partly covered or already covered, and asks a person before skipping anything
  • Every generated test is run against staging before a PR is opened

Outcome

A phased architecture with an evidence-based estimate: 3–6 weeks for a CLI MVP, 6–8 weeks for an agent wired into Jira and CI.

Platform · Full-stack AI build

Job Match Portal

A shared web app that parses résumés, pulls live jobs from several sources across five cities, and ranks every role by how well it fits each candidate.

Problem

Job hunting across several markets meant checking a dozen boards by hand with no consistent way to judge fit.

Built

  • Résumé parsing (PDF/DOCX) that extracts skills and job titles
  • Job aggregation from Adzuna, Remotive, Arbeitnow, plus LinkedIn and Indeed through Apify
  • Match scoring into Close, Good and Weak tiers, with AI-written fit reasons, skill-gap analysis and cover letters
  • JWT auth, a multi-user dashboard, and save and applied tracking

Consumer · Mobile web app

Milk Ledger

A home-screen app for tracking daily deliveries, with separate 1 L and 0.5 L tabs, an automatic monthly bill and AI insights. It went from idea to installed on a phone in one sitting.

Problem

Monthly bills from the supplier never matched what was actually delivered, and there was no record to check them against.

Built

  • A one-tap calendar per quantity with a running bill pinned to the screen (₹70/L, ₹35/half-litre)
  • AI insights that compare months and point out missed-delivery patterns by weekday
  • Installable on a phone home screen, with a custom icon, and updates reach the device instantly

Why it matters

The approach we use with enterprise clients applies here too: start from a real problem, test the edge cases (does an unmarked day count as missed?) and add AI only where it solves something.
